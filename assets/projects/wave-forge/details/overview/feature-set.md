# Feature Set


## Sound and control

- Change all **amp and cab parameters** in real time, through touchscreen UI, very simliar to the neural DSP plugins.
- Load different **impulse responses** (cabinet convolution). Mic types and Positions in future revisions
- **Save and load presets** that store the tone you created
- A suite of standard effects: delay, overdrive, chorus, reverb and more

## Footswitch control

The amp will connect to an external **MIDI foot-switch pedal**. Each footswitch can be linked to a saved preset, so one press instantly recalls that tone — no looking down at the amp mid-song.

Assigning presets to switches happens in the UI, on a 2D mockup of the pedal. When MIDI arrives with a certain value, the amp switches to the preset assigned to it.

The amp can connect to the footswitch via bluetooth or a physical TRS midi cable. The footswitch is a completely independent project since it has its own power system and can work with literally anything that accepts MIDI signals.

## Physical design

1. **Amp head** — DSP, preamp, guitar input, screen controller
2. **Cabinet** — power amplifier board driving a FX12-F200 speaker
3. **External power supply** — mains in, regulated rails out
